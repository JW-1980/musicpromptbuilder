## 1. STRATEGIC PROPOSITION & SYSTEM MISSION
SunoPrompt Studio translates intuitive, natural-language inputs, visual sliders, and live microphone humming into syntax-correct prompt tokens optimized specifically for Suno v5.5. It bridges the gap between raw musical emotion and strict AI generative syntax without exceeding the 1,000-character ceiling.

---

## 2. HUM-TO-PROMPT DIGITAL SIGNAL PROCESSING (DSP) ENGINE
The in-browser Web Audio API signal processing pipeline extracts musical features from microphone input and maps them into Suno v5.5 prompt tokens in real time.

* **Web Worker DSP Offloading:** All heavy mathematical processing (Autocorrelation, FFT analysis) is offloaded to a background Web Worker, ensuring the main UI thread stays at 60 FPS.
* **Debounced Audio Analysis & Noise Gate:** Evaluates Root Mean Square (RMS) energy. If $\text{RMS} < 0.015$, it debounces to prevent CPU thrashing during silence.
* **Autocorrelation Algorithm:** Extracts fundamental frequency ($F_0$) constrained between $65\text{ Hz}$ and $1050\text{ Hz}$.
* **Harmonic Valence & Mode Classifier:** Analyzes the 12-pitch histogram to identify root key and emotional mode (e.g., Major 3rd maps to *euphoric anthem*; Minor 3rd maps to *melancholic depth*).

---

## 3. TRI-MODE DYNAMIC AI ACOUSTIC DISSECTOR ENGINE
A Universal AI Provider Interface to deconstruct infinite artists and abstract concepts without triggering copyright moderation filters.

* **Mode 1: In-Browser Local AI (Zero Cost/Offline):** Runs quantized models (`Qwen2.5-0.5B` or `SmolLM2-360M`) via WebGPU with WASM fallback. Lazy-loads AI weights with a progressive streaming bar.
* **Mode 2: Free Cloud API:** Connects via `fetch()` to free-tier cloud inference providers.
* **Mode 3: Local Ollama:** Connects to a locally running Ollama instance (`localhost:11434`).
* **Automated Fallback Chaining:** If the Cloud API rate-limits, the engine silently fails over to the local WebGPU model.

## 5. DUAL-TARGET ARCHITECTURE & RELATIONAL SCHEMA

### Target 1: Standalone Single-File Engine (`index.html`)
* Complete offline-first execution with all styling, SVG icons, and JS logic embedded.
* DSP and in-browser AI running directly on Web Audio and WebGPU/WASM threads.

### Target 2: Modular PHP 8.4+ & SQLite Micro-Backend
* Front controller routing via `backend/public/index.php`.
* SQLite configured with `PRAGMA journal_mode = WAL;`, `PRAGMA foreign_keys = ON;`, and `PRAGMA busy_timeout = 5000;`.
* `STRICT` table definitions for `presets`, `prompt_history`, and `custom_artists`.
