Microphone unavailable

  1. Allow the permission prompt. If it already closed, click the padlock (or the crossed-out microphone) at the left of the address bar, set Microphone → Allow, then reload and press Record again.
  2. Clear a remembered block. Chrome/Edge: Settings → Privacy and security → Site settings → Microphone. Firefox: Settings → Privacy & Security → Permissions → Microphone. Remove this page from the blocked list.
  3. Windows privacy switches. Settings → Privacy & security → Microphone: turn on Microphone access and Let desktop apps access your microphone. macOS: System Settings → Privacy & Security → Microphone.
  4. Opened from a file? Chrome and Edge treat file:// as an insecure origin and refuse microphone access outright. Serve the folder locally instead — e.g. python -m http.server 8000 in this directory, then open localhost:8000/index.html. Firefox does allow file:// capture after a prompt.
  5. Check the input device. Confirm the right microphone is selected and unmuted in the OS sound settings, that no other app holds it exclusively, and that a USB/Bluetooth mic is actually connected before retrying.
